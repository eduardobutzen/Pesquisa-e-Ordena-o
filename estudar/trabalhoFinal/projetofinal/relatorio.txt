RELATÓRIO DE TEMPOS

Este relatório compara o tempo de ordenação por preço (Insertion Sort e Merge Sort)
e o tempo de busca por id (linear, binária e HashMap) com 1.000, 10.000 e 50.000 produtos.
Os tempos de busca são a média de 1000 buscas. ms = milissegundos, ns = nanossegundos.

Operação                          1.000           10.000          50.000
Ordenação simples (por preço)     0,324 ms        41,470 ms       1469,666 ms
Ordenação eficiente (por preço)   0,124 ms        1,791 ms        9,960 ms
Busca linear por id (média)       223 ns          2599 ns         36386 ns
Busca binária por id (média)      45 ns           64 ns           84 ns
Busca por HashMap (média)         3 ns            5 ns            5 ns
Construção do HashMap             0,010 ms        0,215 ms        1,726 ms
