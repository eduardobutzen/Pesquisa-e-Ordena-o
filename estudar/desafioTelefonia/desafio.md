# Desafio do semestre de hash

Construir um programa em java ou python que:

- Armazene em um HashMap os dados do arquivo 'telephony_sessions.txt', usando como classe a classe implementada em Sessao.java
    - ler o arquivo
    - splitar as linhas
    - criar um objeto do tipo Sessao
    - adicionar (put) no HashMap
- Permite procurar um numero de celular e o retorne seja os dados da Sessao
- Desafio PLUS: Pesquise sobre o uso de threads e tente procurar N celulares ao mesmo tempo
